# Code of Conduct

Good work and good faith — that's what's expected here.

- Be respectful and constructive; assume good faith.
- No harassment, personal attacks, spam, or trolling.
- Keep discussion focused on the work.

The maintainer (@vincentvella) has final say and may edit or remove comments,
commits, issues, or contributions that work against this. Report problems
privately via GitHub (a DM or the repo's Security tab) — not in public issues.
